# 천하: 패왕의 시대

Three.js + Rapier 기반의 한국어 3D 전술 전략 게임입니다. 옥패의 부름으로 무장을 모집·강화하고, 장수 스킬과 진형을 운용해 실시간 전장 **황혼의 관문**을 돌파합니다.

## 실행

```bash
pnpm install
pnpm dev       # Vite 3000 + online API 3001
pnpm typecheck
pnpm test
pnpm build
pnpm smoke
```

개발 서버는 `PORT`, `API_PORT`, `HOST` 환경 변수로 조정할 수 있습니다. `pnpm build`는 `dist/`에 정적 게임 페이지를 만들고, 게임 공유 메타데이터·파비콘·라우트 매니페스트를 함께 생성합니다. 온라인 배포는 `server/Dockerfile`의 API 컨테이너와 `dist/` 정적 게임을 `/api/*` 기준으로 결합합니다.

## 게임 흐름

- **대장전**: 오늘의 작전과 현재 출전 진형을 확인합니다.
- **무장 모집**: 게임 내 재화로 1회 또는 10회 모집을 진행하고, 중복 무장은 성급으로 전환합니다.
- **장수 도감**: 기존 핵심 장수에 유비·조조·손권·장료·육손·방통·초선 등 삼국지 장수 50명을 더해 총 65명의 모집 풀을 제공합니다.
- **무장 관리**: 장수의 능력치·스킬을 확인하고 강화·출전 편성을 관리합니다.
- **영토·내정**: 총 25개 도시를 선택해 자원 수확과 건물 강화를 진행합니다. 아군 도시에서는 수비대 출격으로 방어전을 치러 성벽과 민심을 회복하고, 위나라·오나라 전선에서는 세력전으로 적 수비대와 충돌해 공성 진전과 세력전 공헌도를 확보합니다. 중립·적대 도시에는 식량·은전·철을 소모해 공성 출정을 보내고, 여러 차례 쌓은 점령 진전이 100%가 되면 점령 보상과 함께 촉한 영토로 편입합니다. 각 전투에는 재정비 시간이 적용됩니다.
- **기술 연구**: 농정·상업·군제·학술 4개 분야의 총 58개 기술(기존 8개 + 신규 50개)을 선행 조건에 따라 해금합니다. 농업·교역·전투·방어·세력전·장수 성장 효과가 실제 게임 규칙에 적용됩니다.
- **전장 출정**: 황혼의 관문에서 장수를 선택하고 좌·중앙·우 기동과 스킬을 지휘합니다. 전투는 서막·협곡 포위·결전의 3막으로 진행되며, 적의 좌익 포위·중앙 돌파·우익 유인 패턴을 읽어 같은 방향으로 파훼해야 합니다. 연계가 쌓이면 스킬이 증폭되고, 전술 게이지로 철벽·유인책·전군 돌격을 선택할 수 있습니다. 잘못된 명령은 위협도를 올려 패배로 이어집니다.
- **천하 랭킹 / 계정 관리**: Manus 계정으로 로그인하면 계정별 핵심 진행도와 전적을 데이터베이스에 저장하고, 공유 랭킹에 작전 점수를 기록합니다. 로그인하지 않아도 로컬 플레이는 계속할 수 있습니다.
- **관리자 센터**: 운영 개요, 서비스 상태, 장수 콘텐츠 필터, 시즌 게시 미리보기, 변경 기록을 확인합니다. 실제 계정 목록·게임 상태 조회와 역할 변경은 관리자 전용 서버 라우터와 데이터베이스를 사용합니다.
- **로그인 계정 관리**: 관리자 센터의 `로그인 계정` 탭은 Manus OAuth 사용자 목록을 관리자 전용 서버 라우터에서 조회하고, `user`/`admin` 역할을 데이터베이스에 저장합니다. 로그인하지 않았거나 관리자 권한이 없는 세션에는 계정 목록 대신 접근 차단 상태를 표시하며, 현재 관리자 자신의 권한은 스스로 해제할 수 없습니다.

## 온라인 기능

- `server: true`, `database: true`가 활성화된 Webdev 하이브리드 배포를 사용합니다.
- 로그인은 Manus OAuth와 `webdev_app_session` 세션 쿠키를 사용합니다.
- 계정 저장은 자원·명망·병서·승리 수·최고 전투 점수를 보호된 `account.saveGameState` 절차로 저장합니다.
- 공유 랭킹 보드는 `war-score-v1` / `v1` 규칙 버전이며, 전투 시작 시 티켓을 발급하고 결과 확정 시 한 번만 제출합니다.
- 실시간 멀티플레이 전투는 권위 서버와 Cloud Computer 연결이 필요하며, 현재 프로젝트의 온라인 계정 기능과 분리된 후속 작업입니다.

## 프로젝트 구조

| 경로 | 역할 |
| --- | --- |
| `src/engine/` | 고정 시뮬레이션 루프, 렌더러, 입력, 물리, 저장, 오디오 |
| `src/game/` | 전략 상태·규칙, 3D 전장, 장수·부대 연출 |
| `src/ui/` | HTML/CSS 기반 지휘 사령부 UI |
| `src/styles/` | 다크 청록·옥색 중심의 전술 사령부 스타일 |
| `public/assets/` | 장수·병종·전장 이미지 에셋 |
| `server/` | Manus 계정·저장·리더보드 연동 어댑터 및 DB 마이그레이션 |
| `tests/` | 규칙, 저장, 국제화, 전략·영토 및 미리보기 테스트 |

## 조작

게임 내 전투 화면에서 장수 선택, 좌·중앙·우 기동, 장수 스킬을 클릭 또는 터치로 조작합니다. UI의 좌측 사령부 메뉴로 각 시스템을 이동할 수 있습니다.

## 에셋·라이선스

번들 폰트는 Figtree, Sora, Noto Sans SC이며 각 라이선스 전문은 `public/fonts/`에 있습니다. 게임 이미지와 파비콘은 `assets/` 및 `public/assets/`에 포함된 원본 프로젝트 에셋을 사용합니다.

- **장수 강화**: 레벨 강화와 성급 상승이 전투 능력치, 스킬 단계, 스킬 위력, 해금 레벨에 직접 반영됩니다.
